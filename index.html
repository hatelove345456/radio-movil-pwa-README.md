Cómo usar

1) Los dos móviles se conectan a la misma Wi‑Fi o a un hotspot (sin internet).
2) Uno pulsa Crear grupo y muestra el código.
3) El otro pulsa Unirse, escanea el código y muestra su código de respuesta.
4) El primero escanea la respuesta. Ya están conectados.
5) Añade esta página a la pantalla de inicio para usarla como app, también sin internet.

Hotspot sin internet

Crea una Wi‑Fi local con un móvil. Los dos se conectan a esa red y pueden hablar aunque no haya luz ni datos.

Android: Ajustes → Conexiones → Compartir conexión → Anclaje Wi‑Fi → Activar. Luego el otro móvil se une a esa Wi‑Fi.

iPhone: Ajustes → Datos móviles → Compartir conexión. Si no tiene SIM, el iPhone no puede crear hotspot: usa un Android como anfitrión.

Evita el “Wi‑Fi de invitados”: muchos lo aíslan y los móviles no se ven.
